# 🎓 CampusConnect

CampusConnect is a responsive student productivity dashboard designed to help students manage their academic activities from one place.

## ✨ Features

- Student dashboard
- Course progress tracking
- Course search
- Task manager
- Notes system
- Daily timetable
- Dark mode
- Local storage
- Responsive design
- Mobile-friendly interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage
- Responsive Web Design

## 📂 Project Structure

```text
CampusConnect/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## 🚀 How to Run

1. Clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.

No database or server is required.

## 🎯 Purpose

The project was created to practice front-end development, JavaScript DOM manipulation, responsive design, user interaction, and browser storage.
